# Portfólio | Bruno Damasceno

Site pessoal feito com HTML, CSS e JavaScript puros, sem dependências.

🔗 **Online:** https://brunods13.github.io/portfolio/

## Recursos
- Tema escuro e claro (lembra a escolha do visitante)
- Layout responsivo, pensado primeiro para celular
- Animações leves ao rolar a página, respeitando `prefers-reduced-motion`

## Estrutura
```
├── index.html   # conteúdo
├── style.css    # estilos e temas
├── script.js    # tema e animações
├── .nojekyll    # publica os arquivos como estão no GitHub Pages
├── LICENSE
└── README.md
```

## Rodando localmente
Basta abrir o `index.html` no navegador, ou subir um servidor simples:

```bash
python3 -m http.server 8000
```

Depois acesse http://localhost:8000.

## Publicação
GitHub Pages: Settings → Pages → Branch `main` → pasta `/ (root)`.
